# Trae2api-cn 本机部署 · 使用手册

> 部署位置：`<INSTALL_DIR>`
> 生成时间：2026-10-18
> ⚠️ 本文含明文密码与 API 密钥，请勿外传、勿上传网盘/仓库。

---

## 1. 它是什么

把 Trae CN 账号的模型通道包装成 **OpenAI / Anthropic 兼容 API** 的本地网关（relay）。任何支持 OpenAI 协议的客户端（DeepSeek Harness、Cherry Studio、ChatBox、Codex、Cline、new-api…）都能接进来用。

支持三套协议：

| 协议 | 路径 |
|---|---|
| OpenAI Chat Completions | `POST /v1/chat/completions` |
| OpenAI Responses | `POST /v1/responses` |
| Anthropic Messages | `POST /v1/messages` |

|---|---|

### 2.2 API 地址与密钥

| 用途 | Base URL | Key |
|---|---|---|
| 本机客户端 | `http://127.0.0.1:8000/v1` | `<DSH_API_KEY>` |
| 任意设备 | `https://<YOUR_TUNNEL>.trycloudflare.com/v1` | 同上 |
| 通用/备用 | 同上 | `<RELAY_API_KEY>` |

- 两个 key 都有效，可同时使用；要新增/删除 key，改 `.env` 的 `RELAY_API_KEYS`（逗号分隔）后重启 relay。
- `/v1` 只校验 Bearer key，**不**受管理页 Basic 认证保护。

## 3. 启动 / 停止

### 桌面启动器（推荐）

桌面只有一个图标 **「Trae Relay」**，双击弹出一个小窗口，所有操作都在里面：

| 按钮 | 作用 |
|---|---|
| ▶ 启动 | 起 relay + 隧道 + 助手，并把新地址写到桌面 |
| ⟳ 重启 | 改完 `.env` 用这个生效（停止 + 启动） |
| ■ 停止 | 停止全部进程，先列 PID 再结束 |
| 🌐 打开控制台 | 打开本机 `http://127.0.0.1:8000/web/login` |
| 🔑 导出本机凭据 | 从 Trae 客户端读出 token（手动加账号用） |
| 🔄 检查更新 | 对比 GitHub 最新版本 |
| 📄 打开日志目录 | 看 relay / 隧道 / 助手日志 |

窗口顶部会实时显示：relay 是否运行、隧道是否连接、助手是否在线、当前公网地址。

**想加新功能**：编辑 `launcher.ps1` 顶部的 `$Actions` 数组，照着写一行就会多一个按钮，其它地方不用改：

```powershell
@{ Text = '📦  我的新功能'; Kind = 'script'; Path = 'my-task.ps1'; Hint = '说明' }
```

`Kind` 支持 `script`（跑 ps1）、`url`（开网址）、`folder`（开目录）、`exit`（关闭窗口）。

### 命令行启动（等价）

双击 `start-all.bat` 效果一样，它会：

1. 检查 8000 端口，未监听则启动 relay（隐藏窗口）；
2. 启动 Cloudflare 临时隧道；
3. 轮询日志拿到公网地址，写入桌面 `trae-relay-url.txt`；
4. 生成手机授权命令到桌面 `trae-iphone-login.txt`；
5. 启动本机授权助手（127.0.0.1:8765）。

日志目录：`logs\`（`relay.err.log`、`tunnel.log`、`helper.err.log`）。

### 停止

在启动器里点 **「停止」**（或双击 `stop-all.bat`），它会先列出占用 8000/8765 的进程和隧道进程，然后逐一结束，最后确认端口已释放。

也可以命令行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\stop-all.ps1        # 停止
powershell -NoProfile -ExecutionPolicy Bypass -File .\stop-all.ps1 -ListOnly  # 只看状态
```

### 检查更新

在启动器里点 **「检查更新」**（或双击 `check-update.bat`）：读取本地 `APP_VERSION`，请求 GitHub 最新 release 并对比。

> 控制台本身**不会**自动检测更新，也没有更新按钮；`/v1/status` 里的 `build_revision` 只在使用 GHCR 镜像部署时才有意义（源码运行显示 `local`）。

### 手动启动 relay（不开隧道，仅本机）

```powershell
cd <INSTALL_DIR>\Trae2api-cn\Trae2api-cn-main
<INSTALL_DIR>\relay-venv\Scripts\python.exe -m uvicorn src.main:app --host 127.0.0.1 --port 8000
```

## 4. 接入 DeepSeek Harness（DSH）

1. **设置 → 模型 → 添加模型提供商**；
2. 添加方式选 **自定义模型 API**；
3. 按下表填写：

| 字段 | 值 |
|---|---|
| Provider ID | `trae-relay` |
| 显示名称 | `Trae CN Relay` |
| API 协议 | **OpenAI Chat Completions** |
| API 地址 | `http://127.0.0.1:8000/v1` |
| API 密钥 | `<DSH_API_KEY>` |

4. 展开「自定义设置」→ **添加模型**：
   - 模型 ID：`deepseek-v4-flash`（推荐，便宜快）
   - 显示名称：`DeepSeek V4 Flash`
   - 上下文窗口 / 最大输出：留空用默认
5. 保存。

想加更多模型就再点「添加模型」，ID 必须与 `/v1/models` 返回的完全一致（区分大小写）。

> 也可选 `Anthropic Messages` 协议，地址填 `http://127.0.0.1:8000`（不带 `/v1`）。

## 5. 手机访问（iPhone）

**看数据/改设置**：手机装浏览器就够，打开隧道地址 → 输 admin 密码 → 分享 →「添加到主屏幕」。

**新增账号授权**（Trae 强制回调 `127.0.0.1`，所以手机上必须跑一个本机助手）：

1. App Store 装 **iSH Shell**（免费）；
2. 打开桌面 `trae-iphone-login.txt`，把里面**一整行**复制到 iSH 回车；
3. 看到 `本地监听: http://127.0.0.1:8765` 后，回 Safari **直接打开 `http://127.0.0.1:8765`**，点页面里的「使用 Trae 网页授权登录」；
   > 不要从控制台点那个按钮：控制台是 HTTPS 页面，Safari 会拦截它向 `http://127.0.0.1` 发的检测请求，从而误报"未检测到本机授权助手"。控制台检测失败时现在会显示一个 **「点这里打开本机助手」** 链接，点它效果一样。
4. 弹窗里登录 Trae → 授权 → 完成（页面可能卡在"登录和认证中"，属正常，直接关掉，账号已经进去）。

> 更省事的做法：账号都在 **PC** 上登（PC 助手常驻），手机只用来看和切。

## 6. 上游端点怎么选（重要）

控制台「轮询与设置 → 上游端点」，改完立即生效，不用重启。

| 端点 | 上游 | 工具调用 | 单次固定开销 | 适用 |
|---|---|---|---|---|
| **ide**（当前默认） | `/api/ide/v2/llm_raw_chat`（chat_v3） | 原生 tools，支持并行 | 极低 | 日常首选 |
| **solo** | 同上（solo_agent） | 原生 tools | 极低 | ide 异常时备选 |
| remote | `chat_sessions`（Agent 优先） | 文本桥接 | ~2.1 万 tokens | 需要 1M 上下文 |
| work | `chat_sessions`（Work tier） | 文本桥接 | ~2.1 万 tokens | TraeWork 产品线 |
| 自定义 Remote | 同 remote，换 base URL | 文本桥接 | ~2.1 万 tokens | 自建网关 |

**实测数据**（同一句 `hi`，模型 `deepseek-v4-flash`）：

| 端点 | prompt tokens | 耗时 | 本次积分 |
|---|---|---|---|
| ide | 119 | 2.8s | 0.01 |
| solo | 84 | 3.2s | 0.01 |
| work | 21,421 | 5.7s | 0.14 |
| remote | 21,421 | 6.0s | 0.15 |

> remote/work 走 Agent 通道，每次请求都会带上整套 Agent 系统提示 + 工具说明（约 2.1 万 token），所以贵得多。
> 1M Max 上下文**只有 remote** 支持。

## 7. 积分是怎么算的（实测结论）

**大体上：token 越多，积分越多，但不是简单线性换算。** 影响因素：

1. **输入 + 输出 token 总量**（主要因素）；
2. **模型档位**：Pro 比 Flash 贵一个数量级；
3. **缓存命中**：重复的系统提示会便宜一些；
4. 上游按"回合"结算，偶发跳变。

真实记录（来自控制台消费记录）：

| 模型 | 端点 | prompt | completion | 积分 |
|---|---|---|---|---|
| deepseek-v4-flash | ide | 119 | 31 | 0.01 |
| deepseek-v4-flash | solo | 84 | 32 | 0.01 |
| deepseek-v4-flash | work | 21,421 | 11 | 0.14 |
| deepseek-v4-flash | remote | 21,421 | 61 | 0.15 |
| DeepSeek-V4-Pro | remote | 20,751 | 340 | **5.01** |
| DeepSeek-V4-Pro | ide | 410 | 168 | 0.21 |

结论：**选对端点（ide/solo）+ 选对模型（flash 而不是 pro）**，单次成本能差出几十到几百倍。

**测试连通性**：

```powershell
$body = @{ model='deepseek-v4-flash'; messages=@(@{role='user'; content='hi'}); stream=$false } | ConvertTo-Json -Depth 4
Invoke-RestMethod 'http://127.0.0.1:8000/v1/chat/completions' -Method POST `

  -ContentType 'application/json' -Body $body
```

**查状态 / 账号 / 消费记录**：控制台页面即可，或

```powershell
$b='Basic '+[Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes('admin:<ADMIN_PASSWORD>'))
Invoke-RestMethod 'http://127.0.0.1:8000/api/accounts' -Headers @{Authorization=$b}
Invoke-RestMethod 'http://127.0.0.1:8000/api/usage/records' -Headers @{Authorization=$b}
```

**改固定模型（让 auto 永远走某个模型）**：`.env` 里

```ini
TRAE_TASK_MODEL_ROUTING=1
TRAE_SIMPLE_MODEL=deepseek-v4-flash
TRAE_COMPLEX_MODEL=deepseek-v4-flash
```

**自己切换认证源（不用找人）**：

1. 用记事本打开 `Trae2api-cn\Trae2api-cn-main\.env`；
2. 改这一行：

   ```ini
   TRAE_AUTH_SOURCE=auto        # 读本机 Trae CN 客户端登录态，不走网页授权
   # TRAE_AUTH_SOURCE=web-login # 网页授权（会有上游登录频控）
   # TRAE_AUTH_SOURCE=manual    # 只用控制台「手动填写凭证」加的 token
   ```

3. 保存 → 双击桌面 **「重启 Trae Relay」**（停止+启动一步完成）→ 看控制台「概览」里的认证来源。

> 控制台**没有**认证源开关（源码在启动时读 env），账号的增删、启停、切换、签到都在控制台里做；只有这一项需要改文件。

**手动添加账号的凭据从哪来**

控制台登录页下面的「手动填写凭证添加账号」有 5 个字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| Token（Cloud-IDE-JWT） | ✅ | 形如 `eyJhbGciOi...`，很长 |
| Refresh Token | 可选 | 用于自动续期，建议填 |
| User ID | 可选 | 纯数字 |
| Client ID | 已预填 | 保持默认 `ono9krqynydwx5` |
| 备注 | 可选 | 账号标签 |

三个来源：

1. **本机 Trae CN 客户端（推荐）**
   在客户端里登录一次 → 启动器点 **「🔑 导出本机凭据」** → 它会从 `storage.json` 解密并打印 `token / refreshToken / userId`，直接复制粘贴。
   如果提示"未找到可用的 Trae 登录态"，说明客户端当前没登录。
2. **已登录的浏览器（F12）**
   打开 `https://www.trae.cn` 并登录 → F12 → Network → 随便点开一个请求 → 请求头里找
   `Authorization: Cloud-IDE-JWT eyJ...`，`eyJ` 开头那一整串就是 token；
   也可以在 Application → Local Storage → `https://www.trae.cn` 里找含 `token` 的条目。
3. **现有 `.env`**
   `TRAE_TOKEN=` / `TRAE_REFRESH_TOKEN=` / `TRAE_USER_ID=` 三行就是**当前账号**的凭据（只适合迁移，不适合加新账号）。

> token 是明文凭据：不要截图、不要发群里。加不同账号时必须是那个账号自己的 token，混用会互相踢下线。

### 11.3 补丁原文（直接复制）

**补丁 1 —— 管理面 Basic 认证（`src/main.py`，`auth_middleware` 函数之后）**

```python
# ---------------------------------------------------------------------------
# Local hardening: optional HTTP Basic authentication for the management
# surface.  The upstream project publishes every /api/* route without any
# credential check; that is not acceptable once the console is reachable from
# the public internet through a tunnel.  Enabled only when both
# RELAY_ADMIN_USER and RELAY_ADMIN_PASSWORD are set, and it deliberately does
# not cover /v1/* model traffic (those keep the Bearer RELAY_API_KEYS check).
# ---------------------------------------------------------------------------
_ADMIN_USER = os.environ.get("RELAY_ADMIN_USER", "").strip()
_ADMIN_PASSWORD = os.environ.get("RELAY_ADMIN_PASSWORD", "").strip()
_ADMIN_PROTECTED_PREFIXES = ("/api/", "/web/")
_ADMIN_PROTECTED_PATHS = {"/", "/v1/status", "/authorize"}
# The web-login helper posts credentials to this endpoint without Basic auth,
# so it has to stay reachable for the OAuth callback flow to complete.
_ADMIN_OPEN_PATHS = {"/api/web-auth"}


@app.middleware("http")
async def admin_basic_auth(request: Request, call_next):
    if not _ADMIN_USER or not _ADMIN_PASSWORD:
        return await call_next(request)
    path = request.url.path
    if path in _ADMIN_OPEN_PATHS:
        return await call_next(request)
    if path in _ADMIN_PROTECTED_PATHS or path.startswith(_ADMIN_PROTECTED_PREFIXES):
        header = request.headers.get("authorization", "")
        if header.lower().startswith("basic "):
            try:
                decoded = base64.b64decode(header[6:].strip()).decode("utf-8", "replace")
                user, _, password = decoded.partition(":")
                if secrets.compare_digest(user, _ADMIN_USER) and secrets.compare_digest(
                    password, _ADMIN_PASSWORD
                ):
                    return await call_next(request)
            except Exception:
                pass
        return Response(
            content="Authentication required",
            status_code=401,
            headers={"WWW-Authenticate": 'Basic realm="trae-relay"'},
        )
    return await call_next(request)
```

**补丁 4 —— iOS 助手检测兜底链接（`src/main.py` 登录页 JS）**

在 `refreshHelperDownloadLinks();` 之后、`async function startAuth()` 之前插入：

```javascript
function showHelperFallbackLink() {{
  var el = document.getElementById('auth-msg');
  if (!el || document.getElementById('helper-fallback-link')) return;
  var a = document.createElement('a');
  a.id = 'helper-fallback-link';
  a.href = 'http://127.0.0.1:{listener_port}/';
  a.target = '_blank';
  a.rel = 'noopener';
  a.textContent = '点这里打开本机助手';
  a.style.cssText = 'margin-left:6px;color:#8ab4f8;text-decoration:underline;';
  el.appendChild(document.createTextNode(' '));
  el.appendChild(a);
}}
```

并在 `startAuth()` 的检测失败分支里加一行：

```javascript
    showMsg('auth-msg', localHelperError || '未检测到本机授权助手，请先下载并运行当前页面的授权助手。', false);
    showHelperFallbackLink();
    pickHelperPlatformScript();
```

> 注意：这段 JS 在 Python 的 f-string 里，原样保留双层花括号 `{{ }}`。

**补丁 5 —— `.env`**

```ini
RELAY_API_KEYS=<RELAY_API_KEY>,<DSH_API_KEY>
RELAY_ADMIN_USER=admin
RELAY_ADMIN_PASSWORD=<ADMIN_PASSWORD>
TRAE_CLI_WORKDIR=<INSTALL_DIR>\relay-data\cli-work
TRAE_TASK_MODEL_ROUTING=0
TRAE_STRICT_MODEL_MATCH=0
```

`.env` 不会被升级覆盖（升级只替换 `src\`），但要确认这些键还在。

**补丁 6 —— 登录页频控提示（`src/main.py`，登录页 `#auth-msg` 之后）**

```html
  <div style="margin-top:10px;padding:8px 10px;border-left:3px solid #d9a441;background:rgba(217,164,65,.08);color:#d9a441;font-size:13px;line-height:1.6;">
    提示：同一账号 / 同一网络请勿连续点击授权。上游登录接口有频率风控，触发后会提示「X-访问太频繁」，通常需等待 30–60 分钟；连续触发会成倍延长冷却时间。
  </div>
```

### 11.4 一句话结论
**会丢的是 `src\main.py` 和 `src\sse.py` 里的 4 处代码改动**；`.env` 和 `data\` 只要不删就不会丢。按 11.2 的清单走一遍，10 分钟能恢复。

## 12. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 手机打不开控制台 | 隧道地址变了；看桌面 `trae-relay-url.txt` 最新值 |
| 401 Invalid API key | key 不对，或 `.env` 改了没重启 |
| 401 Authentication required | 管理页需要 Basic 认证，输 admin 密码 |
| 502 `All upstream paths failed` | 该模型在当前端点不可用；切 remote 或换模型 |
| `2001 failed to get app config` | raw 端点专属错误，个人账号无权限，别用 `UPSTREAM_MODE=raw` |
| 工具调用丢参数/重复 | remote 的文本桥接不稳，切 **ide** |
| 额度掉得快 | 在 remote/work 上；切 ide/solo，或换 flash 模型 |
| 账号页空白 | 没登录成功；重新授权（PC 或 iSH） |
| 授权时提示「X-访问太频繁」 | **上游登录频控**（按 IP/设备/手机号计数）。立即停手，等 30–60 分钟；期间换出口网络（飞行模式/切热点）；优先改用 PC 客户端登录 + `auto`。
| 重启后 `previous_response_id` 失效 | 进程内缓存，属正常 |

## 13. 安全提醒

- 本服务把**控制台**暴露在隧道上，靠一层 Basic 认证保护；拿到 admin 密码的人可以改上游地址、删账号、看消费记录。
- `/v1` 只认 API key，key 泄露 = 别人可以刷你的积分。
- `.env` 和 `data\accounts.json` 存明文 JWT / refresh token，别同步网盘、别提交仓库。
- 临时隧道地址虽然随机，但没有访问频率限制，别公开发布。
- 供学习/自用；自动化、多账号轮询属于规避 Trae 服务条款，有封号风险。
